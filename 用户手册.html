一、交付包概览

本产品以三种交付包发布，功能完全一致，按目标机器的平台与网络环境选择其一即可：

① Windows 离线包

文件：wvp-windows-offline-3.0.0.zip（约 410 MB）
依赖：无（内置 JRE21 / MySQL8 / Redis / ZLMediaKit / WVP）
适用：Windows 10 / 11（64 位），不需要 Docker
方式：解压后双击 start.bat（绿色版，删除目录即卸载）

② Linux 离线包

文件：wvp-linux-offline-3.0.0.tar.gz（约 796 MB，解压约 2 GB）
依赖：目标机需预装 Docker Engine 20.10+ 与 compose 插件（v2）
适用：无外网的 Linux x86_64 服务器（镜像已内置，无需构建/拉取）
方式：install.sh → start.sh（三步走）

③ Linux 在线版

形式：linux/online/ 源码目录（编排 + 配置模板）
依赖：Docker + 外网（现场构建 wvp 镜像、拉取依赖镜像）
适用：可联网 Linux 服务器，首次构建约 15~40 分钟
方式：改 .env → docker compose up -d --build

端口与账号速查

项目默认值
Web 访问地址http://<服务器IP>:18080
WVP 管理员admin / admin
国标设备接入SIP 服务器 ID 34020000002000000001；域 3402000000；端口 5060；密码 12345678
RTP 收流（单端口）20000（tcp+udp，默认模式）
其他端口18080 / 5060 / 9092 / 554 / 1935 / 8000 / 9000，详见第六章
提示：三种包使用同一套默认账号与端口；国标设备接入参数（SIP ID / 域 / 密码）三者也完全一致，换包不换设备配置。

二、Windows 离线包（原生进程，免 Docker）

2.1 运行环境要求

项目要求
操作系统Windows 10 / 11（64 位）
内存建议 4 GB 以上（8 GB 可支持更多路预览）
磁盘安装约 1 GB + 数据/录像空间（按需预留）
其他软件无需 Docker、Java、MySQL、Redis（全部自带）
端口18080 / 5060 / 9092 / 554 / 1935 / 20000 / 8000 空闲（未被其他软件占用）

2.2 安装与启动（三步）

  1. 解压 将 wvp-windows-offline-3.0.0.zip 复制到目标机器，解压到任意目录。 建议使用英文、无空格的路径（如 D:\wvp）。
  2. 一键启动 双击目录中的 start.bat，保持命令行窗口打开。 首次启动会自动完成：组件就位 → 生成配置 → 初始化数据库（约 1 分钟）→ 启动 Redis / ZLM / WVP（约 30~60 秒）。 窗口出现“启动完成”提示即表示就绪（全程约 1~2 分钟）。
  3. 浏览器访问 打开 http://<本机IP>:18080（本机也可用 http://localhost:18080）， 默认账号 admin / admin。
分步安装（可选）：也可以先双击 install.bat 仅完成安装（不启动，便于先检查），再双击 start.bat 启动。
多网卡 / 多 IP 的机器：请显式指定对外 IP，避免把错误的网卡地址写进设备信令： 
powershell -ExecutionPolicy Bypass -File .\start.ps1 -SkipDownload -StreamIp 192.168.1.105

2.3 停止与重启

操作方法
停止全部服务双击 stop.bat（依次优雅停止 WVP → ZLM → Redis → MySQL）
重新启动stop.bat 后再 start.bat
强制重启.\start.ps1 -SkipDownload -Force（等价先执行 stop）

2.4 目录与数据

解压目录\
├── start.bat / stop.bat / install.bat   # 双击入口
├── README.md                            # 包内详细说明
├── runtime\                             # 运行时（首次启动生成）
│   ├── config\application.yml           # WVP 运行配置（调参改这里，重启生效）
│   ├── jre21\ mysql\ redis\ zlm\ wvp\   # 各组件
│   ├── data\                            # 数据库 / Redis 快照 / 录像（**备份此目录**）
│   ├── logs\                            # 运行日志（排障看这里）
│   └── run\                             # 进程 PID（stop.bat 依据）
└── config\  mysql\                      # 配置模板与初始化 SQL
  • 数据备份：关闭服务后复制 runtime\data\ 即可。
  • 重置数据库：停止服务 → 删除 runtime\data\mysql\ → 重新启动（自动重新初始化）。
  • 完全卸载：停止服务后直接删除整个解压目录（无注册表、无系统服务、无开机自启）。

2.5 Windows 常见问题速查

现象处理
提示“禁止运行脚本 / 无法加载 start.ps1”bat 已内置 Bypass；手工运行时加 -ExecutionPolicy Bypass
3306 / 6379 / 18080 / 9092 被占用脚本会中止并提示。先停掉占用程序（如本机已装的 MySQL / Redis 服务）
5060 / 554 / 1935 / 20000 / 8000 被占用仅警告，对应功能不可用（如百度网盘常占 10000，本方案已改用 20000）
ZLM 启动失败 / 9092 无响应查看 runtime\logs\zlm-console.err.log；确认 runtime\zlm\MediaServer.exe 完整
需要截图 / 转推功能将 ffmpeg.exe 放入 runtime\zlm\ 即生效（不影响主流程）
脚本中文乱码ps1 必须保持 UTF-8 带 BOM，请勿另存为 ANSI/GBK

三、Linux 离线包（Docker 镜像内置）

3.1 运行环境要求

项目要求
操作系统Linux x86_64（CentOS / Ubuntu / Debian / 麒麟等均可）
DockerDocker Engine 20.10+ 与 compose 插件 v2（离线包唯一的系统依赖）
内存 / 磁盘内存建议 4 GB+；磁盘 ≥ 10 GB（镜像约 2 GB + 数据空间）
网络无需外网、无需源码、无需 Node / Maven
# 检查 Docker 环境（应输出 v2 版本号）
docker --version
docker compose version

3.2 安装与启动（三步）

  1. 解压 将 wvp-linux-offline-3.0.0.tar.gz 上传到服务器，解压并进入目录： 
    tar -xzf wvp-linux-offline-3.0.0.tar.gz
cd wvp-linux-offline-3.0.0
  2. 安装（导入镜像 + 配置 IP） 执行 ./install.sh --stream-ip <本机真实IP>。 该步骤会 docker load 四个镜像（约 1~3 分钟），并把 .env 中的 Stream_IP / SDP_IP / SIP_ShowIP 替换为你给的 IP。 IP 必须是设备能访问到的本机地址，不能填 127.0.0.1。
  3. 启动并访问 
    ./start.sh              # bridge 网络（通用）
./start.sh --host       # host 网络（Linux 生产推荐，SIP/RTP 直通无 NAT）
    浏览器访问 http://<IP>:18080，默认账号 admin / admin。 首次启动约 1~2 分钟初始化数据库，可用 docker compose logs -f wvp 观察进度。

3.3 停止与数据

./stop.sh        # 停止（自动识别上次的部署模式；数据保留在 ./data）
  • 数据目录：./data（MySQL 库文件、Redis 持久化、录像），down 不会删除数据。
  • 备份：停止服务后复制整个 ./data 目录。
  • 换机 / 换网：重新执行 ./install.sh --stream-ip <新IP> 再启动即可。

3.4 bridge 与 host 两种网络模式

对比项bridge（默认，./start.sh）host（./start.sh --host）
原理容器在独立网段，端口映射到宿主机WVP / ZLM 直接使用宿主机网络栈
SIP / RTP多一层 NAT，个别网络环境需调参无 NAT，SDP 地址天然正确，收流更稳
收流模式单端口 20000（默认）多端口 30000-30500（默认开启）
防火墙放行 20000 tcp+udp放行 20000 + 30000-30500 tcp+udp
平台全平台（Windows/macOS 的 Docker 亦可用）仅 Linux
建议功能验证、非 Linux 环境Linux 生产环境
切换模式：先 ./stop.sh，再以另一种参数启动（如 ./stop.sh → ./start.sh --host）。两种模式共用同一份 .env 与 ./data，切换不丢数据。

3.5 Linux 离线包常见问题速查

现象处理
docker load 失败确认 Docker 已运行（docker info）、磁盘充足（镜像约 2 GB）；Docker < 20.10 请先升级
提示“以下镜像未加载”先执行 ./install.sh（或带 --stream-ip）再启动
页面打不开确认容器运行（docker ps）、18080 未被占用、防火墙放行；首次启动需等 1~2 分钟
页面能开但设备注册不上 / 预览黑屏① .env 三个 IP 必须是本机真实 IP（重跑 ./install.sh --stream-ip）；② 防火墙放行 5060 tcp+udp 与 20000 tcp+udp；③ bridge 仍有 NAT 问题时改用 ./start.sh --host

四、Linux 在线版（现场构建）

适用于可联网的 Linux 服务器：现场构建 WVP 镜像（含前端）并拉取依赖镜像，首次约 15~40 分钟。

  1. 准备目录 将仓库中的 linux/online/ 目录整体拷贝到服务器（或克隆仓库）。
  2. 修改 .env 编辑 .env，把 Stream_IP / SDP_IP / SIP_ShowIP 改为本机真实 IP；如需改端口 / 密码也在该文件中调整。
  3. 构建并启动 
    docker compose up -d --build                        # bridge 网络
# 或 Linux 生产推荐：
docker compose -f docker-compose.host.yml up -d --build
    浏览器访问 http://<IP>:18080，账号 admin / admin。
常用命令说明
docker compose logs -f wvp查看 WVP 启动日志
docker compose restart wvp改完 config/application.yml 后重启生效
docker compose down停止并删除容器（数据保留在 ./data）
docker compose up -d再次启动（镜像已构建）
在线版与离线版的关系：两者编排与配置逐字节一致；离线包 = 在线版目录 + images/ 镜像包 + 三个安装脚本。在线版的详细说明见包内 README.md。

五、首次使用与设备接入

5.1 登录平台

  1. 打开页面浏览器访问 http://<服务器IP>:18080，默认账号 admin / admin。
  2. 修改密码登录后建议立即在“个人中心”修改管理员密码，生产环境务必修改。

5.2 接入国标（GB28181）摄像机 / NVR

平台端无需额外配置，在设备（摄像机 / NVR）侧填写平台参数即可。设备注册成功后会自动出现在平台的“国标设备”列表中：

设备侧配置项填写值
SIP 服务器 ID34020000002000000001
SIP 服务器域3402000000
SIP 服务器地址本平台服务器的真实 IP（如 192.168.1.100）
SIP 服务器端口5060
注册密码12345678
设备编码设备自身的 20 位国标编码（设备出厂或自行设置）
传输协议UDP（推荐）
注册成功但预览黑屏？90% 是以下两点：① 服务器防火墙未放行 udp 5060 与 udp 20000； ② 包的 .env（Linux）或 -StreamIp（Windows）里的 IP 不是设备能访问到的真实 IP。

5.3 预览与录像

  • 进入“国标设备”列表 → 点击设备下的通道 → 实时预览；
  • 播放走 ZLM 的 HTTP-FLV / WS-FLV（端口 9092），也可切换 HLS；
  • 录像文件保存在数据目录（Windows runtime\data\record，Linux ./data/record）。

六、端口与防火墙

端口协议用途是否必须放行
18080tcpWVP Web / API（浏览器访问）是
5060tcp+udpSIP 信令（设备注册）是（尤其 udp）
9092tcpZLM HTTP（播流 + API）是
554 / 1935tcpRTSP / RTMP按需
20000tcp+udpRTP 收流（单端口，默认模式）是（尤其 udp）
30000-30500tcp+udpRTP 多端口收流（仅 Linux host 模式默认开启）host 模式必放
8000 / 9000tcp+udp / udpWebRTC / SRT按需

6.1 Windows 防火墙

# 以管理员身份运行（放行 Web、SIP、RTP）
New-NetFirewallRule -DisplayName "WVP-Web" -Direction Inbound -Protocol TCP -LocalPort 18080 -Action Allow
New-NetFirewallRule -DisplayName "WVP-SIP-TCP" -Direction Inbound -Protocol TCP -LocalPort 5060 -Action Allow
New-NetFirewallRule -DisplayName "WVP-SIP-UDP" -Direction Inbound -Protocol UDP -LocalPort 5060 -Action Allow
New-NetFirewallRule -DisplayName "WVP-RTP-UDP" -Direction Inbound -Protocol UDP -LocalPort 20000 -Action Allow

6.2 Linux 防火墙

# firewalld（CentOS / 麒麟等）
firewall-cmd --permanent --add-port=18080/tcp
firewall-cmd --permanent --add-port=5060/tcp --add-port=5060/udp
firewall-cmd --permanent --add-port=20000/tcp --add-port=20000/udp
firewall-cmd --reload

# ufw（Ubuntu / Debian）
ufw allow 18080/tcp
ufw allow 5060/tcp
ufw allow 5060/udp
ufw allow 20000/tcp
ufw allow 20000/udp

# host 模式还需放行多端口段：
firewall-cmd --permanent --add-port=30000-30500/tcp --add-port=30000-30500/udp
切记：云服务器的安全组同样要放行上述端口；只配系统防火墙不配安全组，设备依然注册不上。

7.1 修改方式

对象修改方法
WVP 管理员密码登录后个人中心修改（记不住旧密码时：重置数据库恢复默认，但数据会清空）
SIP 注册密码（Linux）改 .env 的 SIP_Password 后重启 WVP 容器；或 ./install.sh --stream-ip ... 同法
SIP 注册密码（Windows）仅首次初始化生效：.\install.ps1 -SipPassword <新密码>（已初始化需重置库）
MySQL / Redis / ZLM 密钥Linux 改 .env；Windows 传参 -MysqlRootPassword -MysqlPassword -RedisPassword -ZlmSecret（均仅首次初始化生效）

7.2 安全建议（生产环境）

  • 立即修改 WVP 管理员密码与 SIP 注册密码，不要沿用默认值；
  • 用显式参数固定对外 IP（Windows -StreamIp；Linux --stream-ip），避免多网卡选错地址；
  • 仅放行必要端口，MySQL / Redis 不要暴露到局域网；
  • 视频链路优先使用 http://IP:9092 直连播放（http-flv）；
  • 定期备份 data 目录与 .env（或 Windows 的 runtime\config）。

八、常见问题（FAQ）

通用

问题处理
页面能打开，但设备注册不上① 检查设备侧 SIP 地址/端口/域/密码；② 放行 udp 5060（云服务器还要放安全组）；③ 设备与服务器需网络可达
设备注册成功，但预览黑屏① .env/-StreamIp 的 IP 不是设备可达的真实 IP；② 未放行 udp 20000（Linux host 模式为 30000-30500）；③ bridge 模式 NAT 问题时改用 host 模式
重启后要等多久Windows 约 30~60 秒；Linux 首次约 1~2 分钟（初始化数据库）。日志可见“启动完成”或 WVP 就绪
换了一台机器 / 换了网段Linux：重跑 ./install.sh --stream-ip <新IP> 再启动；Windows：.\start.ps1 -SkipDownload -StreamIp <新IP>
系统时间不对会导致注册失败吗会。SIP 注册带时间校验，请确保服务器时间准确（建议开启 NTP 时间同步）
在 WSL2 里运行 Linux 版主机浏览器用 http://localhost:18080 访问最稳；若要用局域网 IP 访问，需在 %USERPROFILE%\.wslconfig 启用 networkingMode=mirrored 与 [experimental] hostAddressLoopback=true，并 wsl --shutdown 重启

Windows 专属

问题处理

本机已装 MySQL / Redis 服务先停止系统服务（占用 3306 / 6379 会导致启动失败），再启动本包
中文乱码ps1 必须保持 UTF-8 带 BOM；请用原包文件，勿转码

Linux 专属

问题处理

九、数据备份、升级与卸载

9.1 数据位置与备份

平台数据目录备份方法
Windowsruntime\data\stop.bat 后复制该目录
Linux./data（编排目录下）./stop.sh 后复制该目录

数据包含：MySQL 数据库（设备/通道/用户/配置）、Redis 快照、录像文件。

9.2 升级版本

  1. Windows解压新版本包到新目录 → 把旧目录的 runtime\data 复制到新目录对应位置 → 启动 start.bat（配置每次启动自动重新渲染，无需手工迁移）。
  2. Linux解压新包 → ./install.sh --stream-ip <IP> → ./start.sh；数据在 ./data，升级不丢（跨大版本升级前先备份）。

9.3 卸载

平台卸载方法
Windowsstop.bat 后直接删除解压目录（无注册表、无系统服务、无开机自启残留）
Linux./stop.sh → 删除解压目录；如需清理镜像：docker rmi wvp-pro:3.0.0 mysql:8.0 redis:7-alpine zlmediakit/zlmediakit:master
